# PoseBook - Picture-Perfect Shoot Platform

PoseBook is an interactive web platform designed for photographers, models, and visual directors to discover curated poses, lighting diagrams, aesthetic moodboards, and connect with creative talent.

## 🚀 Quick Start / How to Run

1. Unzip `posebook-platform.zip`
2. Open `index.html` in any web browser.

## 🌟 Features

- Pose Discovery & Masonry Grid
- 10,000+ Curated Reference Ideas
- Aesthetic Hive Mood Matrix
- Verified Photographers Directory
- Lighting Diagrams & Camera Gear Recipes
